# 血缘分析：必经上游（直接支配节点）

## 交付内容

| 文件 | 作用 |
|---|---|
| `dominance.py` | 核心实现 `analyze(n, root, edges)` |
| `reference_dominance.py` | 独立对照：小图删点定义法 + 位集数据流法 |
| `verify.py` | 完整核验：样例、结构用例、穷举/随机对照、规模实测 |
| `demo.py` | 真实血缘图演示 + 逐产物删点复核 |
| `.pointwise-runtime.json` | 可执行核验入口与实测数据 |

## 语义

`edges` 中 `(u, v)` 表示数据可从 `u` 流向 `v`。返回长度为 `n` 的列表：

- `result[root] = root`；
- 从 `root` 不可达的节点为 `None`；
- 其余 `v` 返回**直接支配节点**：除 `v` 外、出现在从 `root` 到 `v` 的**每条**有向路径上的、离 `v` 最近的节点。

关键点：某次遍历（BFS/DFS）看到的父节点只是**一条路径的见证**，不是必经依赖。
例如 `0→1→3` 且 `0→2→3` 时，遍历父节点可能是 1，但正确答案是 0。

## 算法与复杂度

Lengauer–Tarjan（路径压缩版 `eval`/`link`）：

- DFS 与 `eval` 均为显式栈迭代实现，**不递归**，与递归上限无关；
- 时间 `O((n + m) log(n + m + 2))`（LT 近线性，同时满足更松的 `O((n + m) log n)`）；
- 额外空间 `O(n + m)`。

未使用：逐节点删点重搜、路径枚举、保存每个节点的完整支配集合、提高递归上限。

## 核验入口

```bash
cd /workspace
python3 verify.py    # 全部检查，exit 0 = 通过
python3 demo.py      # 真实血缘演示，exit 0 = 通过
python3 -c "from dominance import analyze; print(analyze(5,0,[(0,1),(0,2),(1,3),(2,3)]))"
# -> [0, 0, 0, 0, None]
```

## 实测（CPython 3.11.2，单核）

| 场景 | n | m | 用时 | analyze 峰值内存 |
|---|---|---|---|---|
| 5 万长链 + 45 万随机边 | 200000 | 500000 | 2.11 s | 81.2 MB |
| 纯 20 万长链 | 200000 | 199999 | 0.32 s | 84.1 MB |
| 长链 + 末节点回边指向每个上游 | 100000 | 199998 | 0.19 s | — |
| 分层 DAG 200×1000 | 200000 | 398000 | 0.90 s | — |

`verify.py` 全套约 10 s，29 项检查全部 PASS；其中包含
`n=200000` 长链在 `sys.setrecursionlimit(100)` 下运行，以及对每个 `n<=4`、
根任意的 10870 个小图（≤4 条边，含自环、平行边）与删点定义法的穷举对照，
及 4000 个 `n=5..7` 随机图的删点对照。
